How This Page Works

This page displays a group of creatures and lets the user click the buttons to learn more about them through visual changes. When the user clicks Show Creature Home, JavaScript changes the background color of each creature based on its habitat, such as land, water, or air. When the user clicks Show Creature Type, JavaScript changes the border style and color based on whether the creature is an animal or an insect. The Clear All button resets the styles back to normal.

The page does this by using document.querySelectorAll() to select all elements with the class creature. Each creature contains custom HTML data attributes, including data-home and data-creature-type. JavaScript reads those values and applies different CSS styles depending on the information stored in each element. This shows how data attributes can be used to organize content and control page behavior dynamically.
